Migration Considerations:
• F64 and above enable free viewer access, eliminating the need for Pro licenses for consumers
• F8, F16, F32 require Pro or PPU licenses for all users (similar to EM SKUs) in Power BI
• Fabric SKUs include additional capabilities beyond Power BI (Data Factory, Synapse, Real-Time Analytics, etc.)
• Consider Azure reservations for ~41% cost savings on annual commitments
• Review the Microsoft Fabric licensing documentation for more details
